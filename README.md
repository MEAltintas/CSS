# 🎨 CSS Projeleri

Bu repository, **CSS ile geliştirilmiş tasarım çalışmaları** içermektedir.  
CSS, web sayfalarının **görünümünü ve stilini** şekillendirmek için kullanılan bir dildir.  

Bu repo içerisinde:  
- ✨ **Animasyonlar**  
- 📐 **Düzen (Layout) Örnekleri**  
- 📱 **Responsive Tasarımlar**  

bulabilirsiniz. 🎯  

---

## 📂 İçerik
- 🔹 **Flexbox & Grid** – Modern sayfa düzenleri  
- 🔹 **Responsive Design** – Mobil uyumlu projeler  
- 🔹 **CSS Animations & Transitions** – Hover efektleri, keyframe animasyonlar  
- 🔹 **UI Bileşenleri** – Button, card, navbar tasarımları  
- 🔹 **Mini Projeler** – Landing page, login sayfası vb.

## 🛠 Kullanılan Teknolojiler
- **CSS3**
